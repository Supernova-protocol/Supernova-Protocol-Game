# 👁️ NOVA CORE: Protocol 51

> **Supernova Launchpad Community Defense Game**

A fast-paced, space-cyberpunk arcade defense web game built using pure HTML5 Canvas and procedural Web Audio. Defend the Supernova Core from malicious inbound vectors, draft rogue-lite upgrades on level-up, and purge the Titan Node bosses attempting 51% network breaches.

---

## ⚡ Game Features

* **360° Omnidirectional Aiming:** Track incoming network threats using smooth touch or mouse controls.
* **Dynamic Core States:** Features reactive visual feedback—from the calibrated cyan/purple neon gradient to the crimson *Volatility Spike* alert mode when threats breach your perimeter.
* **Rogue-lite Upgrade Matrix:**
  * Draft 1 of 3 randomized perks every level: Damage, Overclock (Fire Rate), Aegis Shield, Dynamo Loop (Shield Regen), and Splitter (Multi-Shot).
  * 4 Rarities: **Common**, **Uncommon**, **Epic**, and **Legendary**.
  * Guaranteed **Epic** reward after defeating Level 5 Titan; guaranteed **Legendary** reward after Level 10 Titan.
* **Titan Node Encounters:** Boss fights that introduce minion swarms and massive HP pools.
* **Persistent Command Hub:**
  * Remembers player callsign across sessions.
  * Local high score tracking.
  * Top 5 Operator Leaderboard stored via browser `localStorage`.
* **Zero Dependencies:** Fully self-contained single-file architecture (`index.html`) using native Canvas 2D and procedural Web Audio oscillators.

---

## 🎮 How to Play

1. **Aim:** Move cursor or drag finger across the screen.
2. **Fire:** Click, tap, or hold to unleash energy pulses.
3. **Draft:** Level up by harvesting XP shards to unlock new defensive protocols.
4. **Ascend:** Purge Boss Nodes to trigger the core reboot sequence.

---

## 🚀 Deployment

This project requires zero build steps or package managers.

### Run Locally
Simply open `index.html` in any modern web browser.

### Deploy to Vercel / GitHub Pages
1. Push `index.html` to the root of your GitHub repository.
2. Link the repository to **Vercel** or enable **GitHub Pages** under repository settings.
3. Your deployment will be live in seconds.
